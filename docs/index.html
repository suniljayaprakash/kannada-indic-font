Nanni Indic Font

A beautiful handwriting font for Indic scripts

Font Showcase

Note: This font currently supports Kannada, English, and Vedic Extended characters. It also includes vowels for Konkani, Havigannada, and Badaga.

ಜ್ಯೇ॒ಷ್ಠ॒ರಾಜಂ॒ ಬ್ರಹ್ಮ॑ಣಾಂ ಬ್ರಹ್ಮಣಸ್ಪತ॒ ಆ ನಃ॑ ಶೃ॒ಣ್ವನ್ನೂ॒ತಿಭಿ॑ಸ್ಸೀದ॒ ಸಾದ॑ನಮ್ ॥


ಸರಸ್ವತೀ ಸೂಕ್ತ (ಋಗ್ವೇದ)

ಶ್ರೀಲಕ್ಷ್ಮೀ ನೃಸಿಂಹ ಸ್ತೋತ್ರ

ಶ್ರೀಮತ್ಪಯೋನಿಧಿನಿಕೇತನ ಚಕ್ರಪಾಣೇ ಭೋಗೀಂದ್ರಭೋಗಮಣಿರಂಜಿತ ಪುಣ್ಯಮೂರ್ತೇ |
ಯೋಗೀಶ ಶಾಶ್ವತಶರಣ್ಯ ಭವಾಬ್ಧಿಪೋತ ಲಕ್ಷ್ಮೀನೃಸಿಂಹ ಮಮದೇಹಿ ಕರಾವಲಂಬಮ್ ||


ಕಪ್ಪೆ ಅರಭಟ್ಟರ ಶಾಸನ
